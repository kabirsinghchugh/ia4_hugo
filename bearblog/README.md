# iA4 Bear Blog Theme

This folder contains a lightweight CSS port of the iA4 Hugo theme for [Bear Blog](https://bearblog.dev).

## Files

- `ia4-bear.css` – drop the entire file into Bear Blog’s **Edit theme CSS** panel.

## Usage

1. Open your Bear Blog dashboard.
2. Navigate to **Settings → Edit theme CSS**.
3. Paste the contents of `ia4-bear.css` into the editor and save.
4. Optionally tweak colours or spacing—variables are defined at the top of the file.

Refer to `portbb.md` for additional selectors supplied by Bear (e.g. `.home`, `.post`, `.blog`) if you want to extend the styling further for custom pages.
