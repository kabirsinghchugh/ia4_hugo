Welcome to our new Hugo-powered blog! This is a demonstration of how the iA4 WordPress theme has been successfully converted to a static Hugo site.

Hugo is one of the most popular open-source static site generators. With its amazing speed and flexibility, Hugo makes building websites fun again.

## Features of This Site

This converted site includes several key features:

- **Math Support**: We've integrated KaTeX for beautiful mathematical expressions like $E = mc^2$ and display equations:

$$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$

- **Clean Excerpts**: Posts display clean three-line excerpts on the homepage and posts page to avoid clutter.

- **Portfolio Gallery**: A dedicated portfolio section with a three-column grid layout for showcasing work.

- **Responsive Design**: The site works beautifully on both desktop and mobile devices.

## Getting Started

This is just the beginning. You can now start adding your own content, customizing the design, and making this site truly yours.

The conversion from WordPress to Hugo maintains the minimalist aesthetic of the original iA4 theme while adding the benefits of static site generation.
