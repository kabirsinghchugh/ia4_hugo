I am a stickler for productivity enhancing apps. I have tried thousands of applications across all possible platforms — Android, Mac, Windows, Linux, Web, and even Terminals (Command Line Interface).

There are a few lessons that I've learned while experimenting with workflows.

- Instead of a Swiss Army Knife of applications that do numerous things, find an app which does one thing but does it really well.

This is because all-in-one applications can be bloated, overwhelming, and intimidating with a steep learning curve to be efficient enough in.
